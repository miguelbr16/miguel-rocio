## Convertir HEIC → JPG

Desde la raíz del proyecto:

```bash
chmod +x scripts/convert-heic.sh
./scripts/convert-heic.sh                  # convierte todo lo de inbox/
./scripts/convert-heic.sh public/photos/asturias
```

En el móvil (iPhone): al compartir, elige **“Más compatible” / JPEG** si puedes, y te ahorras el paso.

## Nombres recomendados

Ejemplos:

- `asturias/01.jpg`, `asturias/02.jpg`…
- `mallorca/playa-01.jpg`
- `mestalla/partido.jpg`
